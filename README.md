# Video Editor Portfolio

A single-page portfolio website for a video editor and motion graphics artist.

## Sections

Hero showreel with an editing timeline, client strip, stats, filterable work grid,
before/after color-grade slider, services, toolkit, process, pricing, reviews, FAQ and contact.

## Editing content

Everything lives in `index.html`:

- Name, tagline and bio: the `hero` section and the header `brand-name`
- Videos: the `WORK` list in the script near the bottom (title, client, category, link)
- Stats: the `data-count` values in the stats section
- Contact: the `emailV` / `waV` fields and the social links

## Run locally

Open `index.html` in a browser. No build step.

## Deploy

Works on GitHub Pages, Netlify or Vercel as a static site.
